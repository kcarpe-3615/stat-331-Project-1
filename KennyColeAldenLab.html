The Data

The following link displays the Kaggle source for one of the csvs used in this lab: https://www.kaggle.com/datasets/ahmedalmadami/2020-2023-nba-data/data

This dataset contains NBA player performance statistics from the 2020-2023 NBA seasons. Each row shows the stats for a particular player in a particular season between 2020-2023. There are a number of different variables that fall into following categories:

  • Player Context: nationality, college, name, height, weight, age
  • Injury Statistics: games missed, cash earned while out, type of injury
  • Team Context: wins, losses, team, division
  • A wide array of advanced game performance stats.

The following link displays the Kaggle source for the second csv used in this lab: https://www.kaggle.com/code/rizal1015/nba-salaries?select=nba_salaries.csv

This csv contains information primarily on each individual players NBA salary and player performance statistics during the 2023 season. This data differs from the previous dataset in that player position, salary, and different player performance statistics are being used.

These datasets are collectively useful to analyze player productivity, salary trends, compare performance between seasons, and identify statistical trends among NBA players. In addition, using these two sources will allow students to practice joining and cleaning datasets in order to solve problems throughout this lab.

Question 2

Now that we have the combined dataset, we would like to analyze high performing positions in the NBA to see if their position is currently being underpaid or overpaid. Win shares is a valuable NBA statistic that estimates the number of wins that a player contributed to their teams success. Since this variable has the potential to be influenced by players who play more minutes throughout a season, we can use the WS/48 variable which produces the win shares estimated per 48 minutes which reduces the influence of a player playing more minutes.

Question 3

In Question 2, we compared positions using median salary and median WS/48 separately, but those summaries don’t directly tell us how efficiently teams are spending money on individual players. A player who produces high win shares on a small contract represents much better value than a similarly productive player on a max contract. To explore this, we can build a reusable function that summarizes player-level value within a single position, making it easy to compare any two positions side-by-side. Write a function that takes in a position and returns a summary table for players in that position. The table should include each player’s name, salary, WS/48, VORP, games missed, and a new variable called salary_per_WS48, calculated as salary divided by WS/48. Use the function to compare two different positions from Question 2 and determine which position appears to provide better value relative to salary.

Code for Question 3

position_value <- function(pos_name) {
  nba_combined |>
    filter(Position == pos_name, !is.na(`WS/48`), `WS/48` > 0) |>
    mutate(
      salary_per_WS48 = Salary.x / `WS/48`
    ) |>
    select(
      `Player Name`,
      Position,
      Salary.x,
      `WS/48`,
      VORP,
      `Games Missed`,
      salary_per_WS48
    ) |>
    arrange(salary_per_WS48) |>
    kable(
      col.names = c(
        "Player",
        "Position",
        "Salary",
        "WS/48",
        "VORP",
        "Games Missed",
        "Salary per WS/48"
      ),
      digits = 2
    )
}

Question 4

While the tables from Question 3 are useful, a visualization can make value comparisons across positions much clearer. Using the combined dataset from Question 1, create a nicely formatted ggplot that compares WS/48 and Salary across positions. Your graph should:

  • Display all positions with more than 10 players (from Question 2)
  • Make it visually clear which positions tend to produce more win shares per dollar spent
  • Include informative axis labels, a title, and a caption noting the data source
  • Apply a clean theme (e.g., theme_minimal() or theme_bw())
nba_combined |>
  group_by(Position) |>
  filter(n() > 10) |>
  ungroup() |>
  filter(!is.na(`WS/48`), !is.na(Salary.x)) |>
  ggplot(aes(x = `WS/48`, y = Salary.x / 1e6, color = Position)) +
  geom_point(alpha = 0.6, size = 2) +
  geom_smooth(method = "lm", se = FALSE, linewidth = 1) +
  scale_y_continuous(labels = scales::label_dollar(suffix = "M")) +
  labs(
    title = "Salary vs. Win Shares per 48 Minutes by Position",
    subtitle = "Flatter trend lines indicate positions where higher salaries are not strongly tied to better production",
    x = "Win Shares per 48 Minutes (WS/48)",
    y = "Salary (2023 Season)",
    color = "Position",
    caption = "Source: Kaggle NBA datasets (2020–2023)"
  ) +
  theme_minimal() +
  theme(
    plot.title = element_text(face = "bold", size = 14),
    plot.subtitle = element_text(color = "gray40", size = 10),
    legend.position = "bottom"
  )
`geom_smooth()` using formula = 'y ~ x'

Based on the graph, point guards (PG) appear to provide the best value relative to salary and tend to cluster in the higher WS/48 range without commanding the highest salaries, meaning teams are getting strong per-minute production at a lower cost. Centers (C), by contrast, show a wider salary spread without a proportional increase in WS/48, suggesting some centers are overpaid relative to their win-share contribution. This is consistent with the conclusion from Question 3, where PGs had a lower salary-per-WS/48 than Cs.
